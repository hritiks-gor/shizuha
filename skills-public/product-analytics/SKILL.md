# Product Analytics

State the decision and the user outcome before choosing metrics. Define event semantics, denominators, time windows and the relevant population. Prefer task completion and retained value over activity counts with no connection to the outcome.

Validate instrumentation for missing, duplicate or delayed events and synthetic traffic. Document changes in event definitions and deployment versions. Minimize personal data and avoid logging credentials or raw user content.

Use funnels to locate journey loss and cohorts to compare retention at equal ages. Segment where role, device or experience materially changes behavior, without cherry-picking favorable slices. Compare against a baseline and monitor reliability, latency and accessibility guardrails.

Corroborate quantitative trends with qualitative evidence. Report sample size, uncertainty and limitations, then connect the finding to a concrete decision. Preserve reproducible query definitions and date ranges so another reviewer can verify the result.
