# Public skills

Twelve standalone, original guidance documents for engineering, research and product work. These skills are reviewed for publication and licensed under AGPL-3.0-or-later. They do not grant permissions or override the host application, repository or user instructions. All are reference skills, loaded when relevant.

`manifest.json` records the exact approved SKILL.md SHA-256 digest for each skill. Change the digest when editing a skill, and review both changes together. Run `node scripts/materialize-public-skills.mjs --check` to verify the catalog. The release and CLI bundle use this same checked catalog.

The runtime defaults to the public repository's `skills-public` directory. Existing Git skill checkouts retain their configured origin. See `docs/public-skills.md` in the repository for synchronization and override behavior.
